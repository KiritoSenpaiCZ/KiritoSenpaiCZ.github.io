Highflight Subtitles Repository

Kodi addon repository bundling the Hiyori, WoSir, Edna and Kamui-Subs subtitle addons in one installable source.

Install in Kodi

  1. Settings → File manager → Add source → enter https://kiritosenpaicz.github.io/
  2. Add-ons → Install from zip file → pick that source → click the repository link below.
  3. Add-ons → Install from repository → Highflight Subtitles Repository → install any of the four subtitle addons.

Files

  • repository.highflightsubtitles-1.0.0.zip — install this one first
  • service.subtitles.hiyori-1.0.0.zip
  • service.subtitles.wosir-1.0.0.zip
  • service.subtitles.edna-1.0.0.zip
  • service.subtitles.kamui-1.0.0.zip
